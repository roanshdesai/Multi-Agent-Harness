# UI Links

All my UI resources in one place. Add new links to the right section.

## Component & inspiration websites
- [21st.dev](https://21st.dev/community/components): community React/Tailwind components
- [Design Spells](https://designspells.com/): micro-interaction catalog with video demos
- [Unlumen UI](https://ui.unlumen.com/): React/Motion components
- [Magic UI](https://magicui.design/docs/components): animated React/Tailwind components
- [SmoothUI](https://smoothui.dev/docs/components): animated React components
- [Mobbin](https://mobbin.com/): mobile app screenshots (needs login)
- [Libraries.dev](https://libraries.dev/): free MIT React UI effect libraries to paste into coding agents
- [Unicorn Studio](https://www.unicorn.studio/): no-code WebGL effects and animated backgrounds
- [Brik](https://brik.space/): AI-generated custom design tools with adjustable controls, exportable or embeddable
- [Lenis](https://lenis.dev/): smooth scrolling library
- [Layers](https://www.getlayers.ai/): prompts to build 3D websites
